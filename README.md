# Zigabyte

A terminal disk usage utility written in **Zig**, in the spirit of [ncdu](https://dev.yorhel.nl/ncdu).

**Status:** early work in progress.

## Requirements

- Zig 0.15 or newer
- A POSIX-compatible terminal (Linux, macOS)

## Build

```sh
zig build              # build into zig-out/
zig build run          # build and run
zig build test         # run tests
```
